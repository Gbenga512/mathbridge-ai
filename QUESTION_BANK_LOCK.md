# MathBridge Question Bank — LOCKED PRODUCT STANDARD

This file is the permanent product requirement for the MathBridge question system.

## Required minimums
- P1–P6: 1,000+ questions per class.
- JSS1–JSS3: 1,000+ questions per class.
- SSS1–SSS3: 1,000+ questions per class.
- WAEC Mathematics practice: 1,000+ questions.
- NECO Mathematics practice: 1,000+ questions.
- JAMB UTME Mathematics practice: 1,000+ questions.

## Required metadata
Every curriculum question must carry a unique ID, class level, term, week, topic, difficulty, four options, correct answer, explanation, learning objective and source type.

## No-repeat rule
MathBridge stores question IDs answered by each student and excludes them from fresh practice and diagnostic selection. A question may only return through an explicitly designed revision/spaced-repetition feature.

## Examination-source rule
Questions generated by MathBridge are labelled `WAEC_STYLE_ORIGINAL`, `NECO_STYLE_ORIGINAL` or `JAMB_STYLE_ORIGINAL`. They must never be presented as official past questions. Genuine past questions require a separately identified, legally usable source/licence and must retain year/exam/paper/question metadata.

## Quality gate
`npm run verify:question-banks` is the mandatory automated gate. It checks minimum counts, unique IDs, duplicate question text, four-option structure, valid answer indexes, topic and term metadata, and examination source tags. The GitHub Actions lock workflow runs this gate and the production build whenever the protected question-bank components change.

Do not reduce these minimums or merge school and examination banks into one undifferentiated source.
